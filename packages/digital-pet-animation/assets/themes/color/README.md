# Color theme creature assets

This directory contains creature, regional egg and attack imports for the Color
theme. Remaining source coverage and host integration are tracked in the [implementation plan](../../../../../docs/lcd-color-implementation-plan.md).

## Source and attribution

The creature frames come from
[sbugallo/opencode-vpet v0.4.1](https://github.com/sbugallo/opencode-vpet/tree/v0.4.1),
commit `ce7b62995b69f0ead1c264626407ad401d6209a6`. That project distributes its
code under Apache-2.0 and credits its sprite sources to:

- [sundeth/omnipet](https://github.com/sundeth/omnipet/tree/main) and the
  [Omnipet Digimon database](https://digimon-db.omnipet.app.br/).
- [Tortoiseshel's Full Color Digimon Dot Sprites](https://withthewill.net/threads/full-color-digimon-dot-sprites.25843/).

The upstream frames were edited/processed by that project. This import preserves
their RGB pixels and transparency, changes their encoding to portable RLE and
selects only creatures used by this repository. Credits describe provenance;
they do not reclassify community artwork as official Bandai artwork. See the
repository's [Apache-2.0 license](../../../../../LICENSE).

## Regeneration

Place `src/data/digimon-data.ts` and `src/data/monster-color-frames.ts` from the
pinned upstream revision in a local input directory, under those two filenames.
The importer reads local files only, verifies both SHA-256 values in
`scripts/color-sprite-source.json` and never executes upstream TypeScript.
From the repository root:

```sh
python3 scripts/import-color-sprites.py --input /path/to/source-directory
python3 -m unittest discover -s scripts/tests -p 'test_color_sprites.py'
npm run test --workspace @jcendal/digital-pet-animation
```

The outputs are `generated/monsters.json`, `catalog.json` and core's
`src/data/color-sprite-identities.json`. Do not edit them manually. To compare
regeneration without changing tracked assets, add `--output-root /tmp/theme-audit`.
Generation is deterministic; checksums cover the complete generated frame file.

The source lock owns explicit variant decisions. Other identities match the
corrected local catalog's official reference directory. Unresolved or ambiguous
references fail generation. Updating upstream requires reviewing the identity
crosswalk, overrides and pose semantics, not just accepting new hashes.

## Runtime format and limitations

Each sprite has an opaque RGB palette with transparent index zero and named
16 × 16 poses. A pose is base64-encoded pairs of unsigned bytes: run length
(1–255), then palette index. Rows are concatenated in row-major order. Runtime
decoding uses `atob`, with bounded lengths and palette validation; zlib is used
only by the Python importer. No network request is needed to resolve a frame.

The snapshot contains 639 distinct sprites and 7,658 source poses for all 650
current save identities. The resolver uses local node IDs so empty legacy sprite
keys, aliases and stage variants remain distinguishable. LCD uses its original
artwork independently; it is not generated by thresholding Color frames.

Local `attack` currently maps to upstream `attack_1`. The upstream `attack_2`
pose is retained for future semantic animation integration. Injury poses map
to same-species `sick` and `refuse` and are explicitly reported as substitutions.
The generic egg has only walking poses; other requests report an idle
substitution. Its chosen Virus Busters design is a deliberate generic visual
choice for old saves, not a regional hatch rule. The separate extras catalog maps ten regional origins to their own two egg poses.
Consumers without regional-origin metadata still use the generic egg.

## Regional eggs and attack extras

`sources/dmc.json` is the resolved Omnipet DMC module. `source-urls.json` records
the 137 downloaded PNG URLs; `extras-provenance.json` records their SHA-256 values,
the module checksum, identity assignments and validation failures. These are
community sprite sources credited above, not newly created official artwork.

Regenerate offline from the checked-in source snapshot (requires Pillow):

```sh
python3 scripts/import-color-extras.py
python3 scripts/generate-color-world.py
```

The importer preserves RGB/alpha and requires exact 3× pixel alignment. It emits
20 regional egg poses and 114 validated attack frames. `attack-37.png`,
`attack-56.png` and `attack-66.png` fail alignment and are excluded, with coordinates
recorded in provenance. Ninety upstream identities have exact unambiguous attack assignments; 60 match
local catalog identities. Remaining identities use an authored generic projectile. Do not
manually edit generated JSON to bypass validation or invent an association.

Color world SVGs live in `digital-pet-fields/assets/themes/color`. They are
initial authored palettes over this repository's original vector geometry,
generated by `scripts/generate-color-world.py`; they are not Omnipet backgrounds.
