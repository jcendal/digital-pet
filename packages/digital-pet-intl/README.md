# Digital Pet Intl

Digital Pet is available in **English, Korean, Spanish, and Galician**.

The web app uses your browser's language on the first visit. Choose a language in
**Options → Language** to keep your preference on that device. Language changes
work offline and preserve your companion and progress.

Cursor follows the editor's language. OpenCode follows your system language, or
the language selected with `DIGITAL_PET_LANGUAGE`. The interface language is
independent of the Japanese or English Digimon names configured in OpenCode.

For adding translations, see the [translation development guide](docs/translations.md).
